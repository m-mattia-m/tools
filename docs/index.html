Tools

A Helm chart for the Tools app: browser-only developer tools served as a static site by nginx (non-root, port 8080).

Install from the OCI registry (GHCR)

helm install tools oci://ghcr.io/__OWNER__/charts/tools --version __CHART_VERSION__

Only pull the chart: helm pull oci://ghcr.io/__OWNER__/charts/tools --version __CHART_VERSION__

Install from the Helm repository

helm repo add tools __PAGES_URL__
helm repo update
helm install tools tools/tools

Expose it with an Ingress

# values.yaml
ingress:
  enabled: true
  className: nginx
  annotations:
    cert-manager.io/cluster-issuer: letsencrypt
  hosts:
    - host: tools.example.com
      paths:
        - path: /
          pathType: Prefix
  tls:
    - secretName: tools-tls
      hosts:
        - tools.example.com
helm upgrade --install tools oci://ghcr.io/__OWNER__/charts/tools -f values.yaml

Try it without an Ingress

kubectl port-forward svc/tools 8080:80
